# Sales Data Analysis – Power BI

##  Project Overview

A Power BI dashboard created to analyze sales, customers, products, costs, and profits.

##  Dataset

**SalesData_1000Rows_WithIssues.csv**

##  Data Cleaning & Transformation

* Removed duplicate records
* Handled missing values
* Corrected data types
* Standardized date format
* Cleaned inconsistent data
* Prepared data using Power Query

##  Tools Used

* Excel
* Power Query
* Power BI
* DAX

##  Dashboard Pages

1. **Sales Performance Overview**
2. **Product & Customer Analysis**
3. **Profit & Cost Analysis**

##  Key Analysis

* Sales trends
* Regional and category sales
* Top products and customers
* Trending products
* Cost and profit comparison
* Profit margin
* Profit trends

##  Objective

To transform raw sales data into an interactive Power BI dashboard and generate useful business insights.
